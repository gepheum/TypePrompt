# TypePrompt Python End-to-End Example

An engaging day-planner and local activity advisor built with Python, TypePrompt, and the official Anthropic Claude Python SDK (`anthropic`), demonstrating **end-to-end typed tool calling** and **structured JSON output**.

---

## Prerequisites

- Python 3.12 or higher
- Node.js 18 or higher (for `bunx @typeprompt/cli`)
- An Anthropic API key (`ANTHROPIC_API_KEY`)

---

## Project Structure

```
.
├── typeprompt.yaml          # TypePrompt configuration
├── requirements.txt         # Python dependencies
├── prompts/
│   ├── meta.tp             # Metadata declaration (model, temperature)
│   ├── getWeather.tp       # Tool definition (Input & Output schema)
│   └── PlanDay.tp          # Prompt template registering the getWeather tool
└── src/
    ├── gen/
    │   └── prompts.py       # Auto-generated by TypePrompt
    └── main.py              # Application entry point & execute_prompt helper
```

---

## 1. Installation

Create a virtual environment and install runtime dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

---

## 2. Generate Code

To generate the typed prompt and tool code from your XML templates:

```bash
bunx @typeprompt/cli gen
```

This generates `src/gen/prompts.py` containing:
- `prompts.plan_day.render(...)` for rendering the prompt with typed arguments (`schema.plan_day.Input`).
- `tools.plan_day.ToolExecutor` protocol enforcing the `get_weather` method signature.
- `schema.get_weather.Input` and `Output` Pydantic models.

---

## 3. Run the Application

Set your Anthropic API key and run the script:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
python src/main.py
```

You can also pass a custom city and personal interests:

```bash
python src/main.py "Paris" "art galleries and warm croissants"
```

or:

```bash
python src/main.py "Tokyo" "street photography and ramen"
```

---

## How It Works

1. **Prompt Resolution**: `prompts.plan_day.render(...)` resolves template placeholders (`city`, `interests`) and binds tool schemas.
2. **Tool Invocation**: Claude decides to call the `getWeather` tool to inspect current conditions in the destination.
3. **Typed Execution**: `prompt.execute_tools(...)` safely dispatches the call to `WeatherExecutor.get_weather(input)` and returns serialized results back to Claude.
4. **Response Validation**: Once Claude produces its recommendation, `prompt.parse_response(...)` validates the final response against the template's output schema.
