# TypePrompt Kotlin End-to-End Example

A command-line translation tool built with Kotlin, TypePrompt, and the official OpenAI Java/Kotlin SDK, demonstrating **structured JSON output**.

---

## Prerequisites

- JDK 17 or higher
- An OpenAI API key

---

## Project Structure

```
.
├── build.gradle.kts
├── settings.gradle.kts
├── typeprompt.yml
├── prompts/
│   └── Translate.xml
└── src/main/kotlin/
    ├── gen/
    │   └── Prompts.kt         # Auto-generated by TypePrompt
    └── Main.kt                # Application entry point & executePrompt helper
```

---

## 1. Generate Code

To generate the typed prompt code from your XML template:

```bash
npx typeprompt gen
```

This generates `src/main/kotlin/gen/Prompts.kt` containing the `prompts.renderTranslate()` function and typed `Schema.Translate.Input` / `Output` definitions.

---

## 2. Run the Application

Set your OpenAI API key and run the CLI tool using Gradle:

```bash
export OPENAI_API_KEY="sk-..."
./gradlew run
```

You can also pass custom text and a target language as arguments:

```bash
./gradlew run --args="'Good morning! How are you doing today?' 'German'"
```
