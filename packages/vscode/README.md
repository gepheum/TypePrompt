# TypePrompt VS Code Extension

VS Code extension for editing [TypePrompt](https://typeprompt.dev) templates.

Powered by `@typeprompt/language-server`.

Official website: [https://typeprompt.dev](https://typeprompt.dev)

## Features

- **Real-Time Diagnostics**: Instant validation for XML syntax, template structure, schema definitions, and project configuration (`typeprompt.yaml`).
- **Autocompletion**: Context-aware completions for XML tags, attributes, attribute values, and configuration options.
- **Go to Definition**: Jump directly to type declarations, schemas, and symbols (`F12` / `Cmd+Click`).
- **Find References**: Find all usages of types and symbols across your templates (`Shift+F12`).
- **Rename Symbol**: Project-wide renaming for types and symbols (`F2`).
- **Document Formatting**: Format XML prompt templates on save or on demand.
- **Semantic Syntax Highlighting**: Rich semantic coloring for prompt elements, schemas, types, and attributes.
